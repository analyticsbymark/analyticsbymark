# Learn

Hands-on tutorials for building insurance data foundations in Python. Each one is tested, so the code you copy is the code that runs.

## Start here

1. [**The data**](data/index.md): where the SpaceX launch data comes from and how it is modelled with Pydantic and SQLModel.
2. [**Launch cadence**](spacex/launch_cadence.md): turn that data into a chart that answers a question.
3. [**Creating policies**](spacex/creating_policies.md): model something closer to an insurance policy table.

New to the tooling? Start with [setting up a virtual environment](virtual_environments.md).

!!! tip "Why SpaceX?"
    A neutral dataset keeps the focus on the technique, not an argument about methodology. The same patterns apply to claims, exposure and policy tables.
