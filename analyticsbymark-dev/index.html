About Me

  • Qualified Actuary - Since 2017
  • Lead Actuarial and Underwriting Analytics Engineer - At The Fidelis Partnership (TFP).
  • Varied Experience - Worked across reserving, pricing, capital modelling and portfolio analytics.
  • Self Taught Coder & Tinkerer - Started to learn to code during my gap year after qualifying.

Proven in Practice

My tutorials come from building and maintaining a real analytics data model — one that centralises insights across 100+ classes of business, $5bn+ in annual GWP and multiple capacity providers.

These aren't textbook patterns. They're lessons I've learned from delivering analytics to Underwriting, Pricing, Capital, Projects, Exposure Management, Ceded Re, Strategic Planning and Corporate Finance teams.

Is this for you?

You might find my site helpful if:

  • 😩 Your time disappears fixing data instead of delivering insight.
  • 🔁 Monthly reporting feels like déjà vu leading to the same “why doesn’t this tie up?” conversation
  • 🤔 You know better analytics is possible — but don't know where to start with scalable data foundations
  • 🧩 You work with messy, inherited datasets that almost work — but feel a few extra columns would have made life easier
  • 🎯 You want to be seen as commercially valuable, not just technically capable

I get it

I've been there — fixing the same reporting issues month after month instead of focusing on real analytics.

Through tutorials and blog posts I teach you:

  • how to query data from APIs
  • how to validate data to a certain schema using Pydantic
  • how to write data to databases using SQLModel
  • how to create visualisations / applications using Plotly

The route forward

  1. Design with intent — Build datasets for the questions they're meant to answer.
  2. Validate and structure properly — Use clear models, documentation, and repeatable workflows.
  3. Deliver insight, not spreadsheets — Connect clean data to meaningful analytics and visualisation.
